# ScribeSteno

Portable, quiet unibody steno keeb, with a RP2040, Low-Profile Choc switches, QMK Firmware + Plover, with a Magnetic Lid, that can be used as a stand.

![render](images/)

## Features
- chord hinting using LED's to show how to write a word
- Magnetic Lid, which is used as a Stand
